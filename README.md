# Copernicus-FM

Copernicus-FM (Copernicus Foundation Model) es un modelo fundacional unificado para observación de la Tierra, preentrenado con el dataset Copernicus-Pretrain a partir de 18.7 millones de imágenes alineadas de las misiones Sentinel de Copernicus (Sentinel-1 SAR, Sentinel-2 multiespectral, Sentinel-3 OLCI y Sentinel-5P atmosférico, además del modelo de elevación Copernicus DEM). El modelo es capaz de procesar cualquier modalidad espectral o no espectral mediante hiperredes dinámicas y codificación flexible de metadatos (geolocalización, área y tiempo), y fue evaluado en Copernicus-Bench, un benchmark sistemático de 15 tareas jerárquicas que abarcan desde detección de nubes hasta clasificación de coberturas del suelo, detección de inundaciones, estimación de biomasa y calidad del aire. Los pesos del modelo se publican bajo licencia CC-BY-4.0 y el código bajo Apache-2.0.
